# Руководство пользователя

## Начало работы

Отправьте боту `/start`. Появится главное меню:

```
[ ✅ Задачи ] [ 🔥 Привычки ]
[ 💰 Финансы ]
[ ❓ Помощь ] [ ⏸ Отключить ]
```

Каждая кнопка открывает раздел со своим подменю. Кнопка «⬅️ Назад» возвращает в главное меню. Во время любого диалога (ввод суммы, названия и т. п.) доступна кнопка «❌ Отмена» или команда `/cancel`: она прерывает диалог и возвращает в меню того раздела, где вы были.

Ботом может пользоваться только владелец (`ALLOWED_TELEGRAM_USER_ID`). Остальным он отвечает «Доступ запрещен».

## ✅ Задачи

| Кнопка / команда | Что делает |
| --- | --- |
| ➕ Новая задача | добавить задачу |
| 📅 Сегодня, `/today` | задачи на сегодня и просроченные |
| 🗓 Неделя, `/tasks` | просроченные и задачи на ближайшие 7 дней, сгруппированные по дням |

**Как добавить задачу.** Нажмите «➕ Новая задача», напишите текст (до 256 символов) и выберите день:

- «Сегодня» или «Завтра»;
- день недели, например «Пт 24.10». Это ближайший такой день, считая сегодняшний;
- «📆 Другая дата»: ввести дату вручную в формате `дд.мм.гггг`.

**Как отметить или удалить.** Под каждым списком у каждой задачи две кнопки: ✅ (выполнено) и 🗑 (удалить). После нажатия список обновляется на месте.

**Просроченные задачи.** Если задачу не закрыли в её день, она не пропадает: на следующий день она показывается в блоке «⚠️ Просрочено» с исходной датой, пока её не отметят или не удалят.

## 🔥 Привычки

| Кнопка / команда | Что делает |
| --- | --- |
| ✔️ Отметить сегодня | опрос по привычкам, ещё не отмеченным сегодня |
| ➕ Новая привычка | добавить привычку (название до 128 символов) |
| 📋 Мои привычки, `/habits` | список с сериями и рекордами, кнопки удаления |

**Отметка.** Для каждой привычки приходит сообщение с кнопками «✅ Сделал» и «⏭ Пропустил». Отметку за сегодня можно поменять: повторное нажатие перезаписывает результат.

**Серия (стрик)** — сколько дней подряд привычка выполнена:
- пока сегодня не отмечено, серия считается по вчерашний день, поэтому днём она не обнуляется;
- «Пропустил» или день без отметки прерывает серию;
- «рекорд» — самая длинная серия за всё время.

В списке «📋 Мои привычки» значок показывает статус на сегодня: ✅ сделано, ⏭ пропущено, ▫️ ещё не отмечено.

Удалённая привычка пропадает из списков и опросов. История отметок при этом сохраняется в базе.

## 💰 Финансы

| Кнопка / команда | Что делает |
| --- | --- |
| 💰 Доход, `/income` · 💸 Расход, `/expense` | добавить операцию: сумма → категория → комментарий (`-`, если без комментария) |
| 📊 Статистика, `/stats` | «Сводка» (доход, расход, баланс, средние в день) или «По категории» (сумма, количество операций, среднее в день) |
| 🏆 Рейтинг, `/rating` | категории доходов или расходов, отсортированные по сумме |
| 🗂 Категории, `/categories` | просмотр, добавление, переименование и удаление категорий |
| 🧾 Последние, `/last` | последние операции, по 10 штук, кнопка «➕ Показать еще» |
| 📥 Отчёт, `/excel` | Excel-файл: только доходы, только расходы или оба файла |

**Сумма** вводится числом: `1250` или `1250.50` (подойдёт и запятая).

**Период** для статистики, рейтинга и отчёта: сегодня, последние 7 дней, текущий месяц или произвольный период в формате `дд.мм.гггг дд.мм.гггг` (например, `01.01.2025 31.01.2025`).

**Категории** свои у доходов и у расходов. По умолчанию создаются:
- доходы: Работа, Подарки, Другое;
- расходы: Еда, Проезд, Одежда, Кино, Покупки, Переводы, Другое.

Категорию, по которой уже есть операции, удалить нельзя.

## Уведомления

| Время (Бишкек) | Что приходит |
| --- | --- |
| 09:00 | «Доброе утро!» и задачи на сегодня вместе с просроченными (с кнопками ✅ / 🗑), плюс число активных привычек |
| 22:00 | «Как прошёл день?» и по сообщению на каждую привычку, ещё не отмеченную сегодня. Если всё отмечено, опроса не будет |

## Отключение бота

«⏸ Отключить» (или `/disable`) ставит бота на паузу: он перестаёт реагировать и не присылает уведомления. Чтобы включить снова, нажмите `/start`.

Пауза сохраняется в базе и переживает перезапуск бота.
