# Документация

Личный Telegram-бот-помощник: финансы, привычки и задачи в одной системе (NestJS, PostgreSQL, одна база). Бот рассчитан на одного пользователя: доступ ограничивается переменной `ALLOWED_TELEGRAM_USER_ID`.

| [Установка и запуск](setup.md) | для тех, кто запускает и деплоит | переменные окружения, локальный запуск, миграции, прод |

| [Как добавить модуль](extending.md) | для разработчика | пошаговый чеклист нового раздела бота |

## Коротко о модулях

- **💰 Финансы.** Доходы и расходы по категориям, сводка, статистика по категории, рейтинг, последние операции, выгрузка в Excel.
- **🔥 Привычки.** Ежедневные отметки «Сделал» / «Пропустил», серии (стрики) и рекорды, опрос в 22:00.
- **✅ Задачи.** Разовые задачи на конкретную дату, списки «Сегодня» и «Неделя», утренний план в 09:00. Невыполненные задачи переносятся с пометкой «просрочено».

Все уведомления и понятие «сегодня» считаются по часовому поясу **Asia/Bishkek (UTC+6)**.
