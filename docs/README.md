# Документация

Личный Telegram-бот-помощник: финансы, привычки, задачи и подписки в одной системе (NestJS, PostgreSQL, одна база). Бот рассчитан на одного пользователя: доступ ограничивается переменной `ALLOWED_TELEGRAM_USER_ID`.

## Коротко о модулях

- **💰 Финансы.** Доходы и расходы по категориям, сводка, статистика по категории, рейтинг, последние операции, выгрузка в Excel.
- **🔥 Привычки.** Ежедневные отметки «Сделал» / «Пропустил», серии (стрики) и рекорды, опрос в 22:00.
- **✅ Задачи.** Разовые задачи на конкретную дату, списки «Сегодня» и «Неделя», утренний план в 09:00. Невыполненные задачи переносятся с пометкой «просрочено».
- **📊 Дашборд (Mini App).** Графики и сводка по финансам прямо в Telegram: кнопка меню «📊 Дашборд» или `/dashboard`.
- **🔔 Подписки.** Регулярные платежи (месяц или год): список с ближайшими списаниями и суммой в месяц, напоминания в 09:00 за 3 дня, за 1 день и в день списания.

Все уведомления и понятие «сегодня» считаются по часовому поясу **Asia/Bishkek (UTC+6)**.
